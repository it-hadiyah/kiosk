# كيوسك هدية للتبرع — Hadiyah Donation Kiosk

تطبيق Flutter (Android) للخدمة الذاتية للتبرع. **نسخة عرض تجريبية: لا يوجد أي ربط بالدفع ولا خلفية (Backend).**

## صفحة البداية
خلفية بملء الشاشة + اختيار اللغة (العربية - Français - English - اردو) + زر «تبرع الآن» الذي يتغير نصه حسب اللغة.
اللغة تنتقل لكل الشاشات، وتعود للعربية عند انتهاء الجلسة.

## رحلة المستخدم (3 خطوات فقط)
1. **اختيار المشروع** — بطاقات كبيرة قابلة للّمس بالكامل.
2. **تحديد المبلغ** — 10 / 50 / 100 / 200 ريال أو مبلغ مخصص بلوحة أرقام داخلية.
3. **محاكاة الدفع** — رسم متحرك لتقريب البطاقة، مراحل (تقريب ← قراءة ← معالجة)، ثم نجاح المحاكاة والعودة تلقائياً للرئيسية.

## ملاحظات
- شارة «وضع تجريبي — لا يتم خصم أي مبلغ» ظاهرة في شاشة الدفع ونتيجتها.
- لا توجد شعارات مزودي دفع ولا بيانات بطاقات ولا SDK مالي.
- 4 لغات (عربي RTL افتراضياً، Français، English، اردو RTL)، خط IBM Plex Sans Arabic، يحترم إعداد تقليل الحركة.
- مهلة خمول 60 ثانية مع تنبيه ثم مسح الجلسة. المقاييس تتكيّف مع الجوال/اللوح/الكيوسك (التصميم الأساسي 1080×1920).
- المشاريع في `lib/data/projects.dart`. مكان الربط الحقيقي لاحقاً: `lib/screens/payment_screen.dart` (`_startSimulation`).

```
flutter pub get
flutter test
flutter build apk --release
adb install -r build/app/outputs/flutter-apk/app-release.apk
```
