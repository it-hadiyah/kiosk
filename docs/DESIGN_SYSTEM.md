# نظام التصميم — لوحة تحكم هدية

مصدر القيم: أول `:root` في `server/public/admin/style.css`.

## الألوان (متغيرات CSS، فاتح/داكن تلقائي)
| المتغير | الاستخدام |
|---|---|
| `--brand` / `--brand-strong` / `--brand-soft` | هوية هدية (الأخضر المزرق): الأزرار الأساسية، العناصر النشطة |
| `--ink` / `--text` / `--muted` | العناوين / النص / النص الثانوي |
| `--bg` / `--card` / `--card2` / `--line` | الخلفية والبطاقات والحدود |
| `--ok` `--warn` `--danger` (+ `-soft` `-ink`) | حالات: سليم / تنبيه / خطأ — لا يُعتمد على اللون وحده، تُرفق معها أيقونة ونص |

## المسافات والخطوط
`--s1…--s6` (4 → 32px)، `--fs-xs…--fs-2xl` (12 → 28px). الخط: IBM Plex Sans Arabic ثم خطوط النظام. الأنصاف: `--r-sm 8` / `--r 12` / `--r-lg 16`.

## المبادئ
- **RTL أولاً**: الخصائص المنطقية (`margin-inline-*`, `border-inline-*`)؛ الأرقام والروابط تُعرض بـ `dir=ltr` عند الحاجة.
- **بطاقات مسطّحة** بحد رفيع بلا ظلال ولا تدرجات؛ الظل للطبقات العائمة فقط (حوارات، أدراج).
- **أربع حالات لكل قائمة**: تحميل (`.skeleton`) / خطأ (`.state.error`) / فارغ (`.state` برسالة وإجراء) / نجاح (`toast` + `#live` للقارئات).
- **تأكيد صريح** لكل إجراء مدمّر أو مؤثر على الكيوسك (`confirmDlg`) يشرح الأثر بالتحديد.
- **لا أرقام وهمية**: ما لا يتوفر من الخادم يُعرض «غير متاح» بصراحة.

## المكوّنات
`.card`، `.btn` (`primary`/`danger`/`small`/`big`)، `.alert` (`info/warn/error`)، `.tbl` (جدول قابل للفرز)، `.pill` / `.tagx` / `.chipx` (وسوم الحالة)، `.dcard` (بطاقة جهاز)، `.pfc` (بند فحص النشر)، `.cmpbox` (مقارنة النسخ).

## الوصولية
حلقة تركيز ظاهرة، أهداف لمس ≥ 44px للأزرار الأساسية، `aria-pressed/aria-live`، تباين الهوية محقَّق في الخادم عند حفظ الألوان، واختبار عدم التمرير الأفقي عند 360px.

## البنية البرمجية
ملفات مشتركة في نطاق واحد بترتيب التحميل: `app.js` (الأساس والواجهة الخلفية) ← `extras.js` ← `overview.js` ← `dashboard.js` ← `content.js` ← `media.js` ← `devices.js` ← `settings.js` ← `publish.js`. الملفات اللاحقة تضيف `regions`/`actions`/`VIEWS` وتستبدل بعض الدوال؛ `refreshRegions` يتخطى المنطقة التي فيها تركيز إلا مع `ui.forceRegions = true`، ويعالج المناطق المتداخلة.
