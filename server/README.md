# خادم الكتالوج + لوحة تحكم كيوسك هدية

خادم صغير **بدون أي اعتماديات** (Node ≥ 18) يخدم:
- لوحة التحكم على `/admin/`
- الكتالوج المنشور على `GET /api/catalog` (يقرؤه التطبيق)
- الصور على `/uploads/…`

## التشغيل
```bash
cd server
ADMIN_PASSWORD='كلمة-مرور-قوية' PORT=8080 node server.js
# لوحة التحكم:  http://localhost:8080/admin/
```
- إن لم تضبط `ADMIN_PASSWORD` تُولَّد كلمة مرور مؤقتة وتُطبع في الطرفية.
- البيانات في `DATA_DIR` (الافتراضي `server/data`): `catalog.json` (المنشور) · `draft.json` (المسودة) · `history/` (آخر 30 نسخة) · `uploads/`.
- أول تشغيل ينسخ البيانات التجريبية من `seed/`.

### Docker
```bash
docker build -t hadiyah-admin .
docker run -d -p 8080:8080 -v hadiyah-data:/data -e ADMIN_PASSWORD='...' hadiyah-admin
```

## ربط التطبيق بالخادم
أثناء بناء التطبيق:
```bash
flutter build apk --release --dart-define=CATALOG_URL=https://your-server.example.com
```
- التطبيق يجلب الكتالوج عند التشغيل، كل 5 دقائق، وبعد كل جلسة، ويحفظ نسخة محلية والصور للعمل بدون إنترنت.
- بدون `CATALOG_URL` يعمل بالكتالوج المضمّن (`lib/data/default_catalog.dart`).
- يُنصح باستخدام **HTTPS**. (التطبيق يسمح بـ HTTP للتجارب فقط.)

## سير العمل في اللوحة
1. عدّل (البرامج / الكتالوجات / الصفحة الرئيسية / الإعدادات) — الحفظ تلقائي كمسودة.
2. راجع المعاينة ثم **نشر التغييرات** ← يظهر في الكيوسكات خلال دقائق أو بعد انتهاء الجلسة الحالية.
3. أخطأت؟ **النشر والنسخ ← استرجاع** نسخة سابقة ثم انشرها.

## الأمان
- كلمة مرور واحدة للمدير، رمز دخول صالح 12 ساعة، وحد 5 محاولات خاطئة في الدقيقة.
- رفع الصور: jpg/png/webp فقط (فحص محتوى الملف) حتى 6MB.
- شغّله خلف HTTPS (Nginx/Caddy/سحابة) ولا تكشف المنفذ مباشرة للإنترنت.
